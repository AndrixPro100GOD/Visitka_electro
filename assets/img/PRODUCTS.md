# Картинки продукции («Энергия в деталях»)

Положите PNG в эту папку **с тем же именем** — HTML уже ссылается на эти файлы.

| Файл | Название на сайте |
|------|-------------------|
| `product-switchgear.png` | Электрощитовое и низковольтное оборудование |
| `product-cables.png` | Кабельная продукция |
| `product-cable-trays.png` | Кабеленесущие системы |
| `product-lighting.png` | Системы освещения и осветительные установки |
| `product-ups.png` | Источники бесперебойного питания |
| `product-fasteners.png` | Строительный крепеж и фурнитура |
| `product-low-voltage.png` | Слаботочные системы |
| `product-security.png` | Системы безопасности |
| `product-kipia.png` | КИПиА |
| `product-computers.png` | Компьютерная техника |
| `product-network.png` | Сетевое и серверное оборудование |
| `product-software.png` | Программное обеспечение |

**Рекомендации:** PNG, прозрачный фон, ~640×400 или больше, объект по центру.

Неиспользуемый файл (не в витрине): `product-electro-profile.png` — можно удалить или переиспользовать.
